DOCKER LAB 1. SERVIDOR
docker pull && docker run

Crea la red aislada y levanta el servidor Redis Alpine en tu PowerShell:

docker pull sickp/alpine-redis
docker network create redis_network
docker run --rm --network redis_network --name redis-server sickp/alpine-redis
DOCKER LAB 2. CLIENTE CLI
docker run ... redis-cli -h redis-server

Abre otra pestaña de PowerShell e inyecta el cliente conectado a la misma red:

docker run --rm --network redis_network -it sickp/alpine-redis redis-cli -h redis-server
CIERRE 3. LIMPIEZA DE HUELLAS
docker kill && network remove

Detiene el servidor y elimina la red virtual de Docker sin dejar rastros:

docker kill redis-server
docker network remove redis_network
